# SysAdmin Multiboot USB

Proyecto personal de un pendrive multiboot basado en Ventoy orientado a administración de sistemas, redes, virtualización y recuperación.

## Hardware

- Kingston DataTraveler Kyson 128 GB
- Ventoy

## Sistemas Microsoft

- Windows XP SP3
- Windows 7
- Windows 8.1
- Windows 10 22H2
- Windows 11 25H2
- Windows Server 2019
- Windows Server 2022
- Windows Server 2025

## Sistemas Linux

- Ubuntu Server 22.04 LTS
- Ubuntu Server 24.04 LTS
- Ubuntu Desktop 24.04 LTS
- Debian 13
- Rocky Linux 10 Minimal
- Kali Linux

## Infraestructura

- Proxmox VE
- OPNsense

## Recuperación y mantenimiento

- Hiren's BootCD PE
- Clonezilla
- GParted Live
- SystemRescue

## Objetivo

Disponer de una herramienta portátil para:

- Instalación de sistemas operativos
- Recuperación de equipos
- Clonación de discos
- Virtualización
- Laboratorios de redes
- Pruebas de ciberseguridad
